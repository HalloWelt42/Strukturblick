JSON Pointer und jq-Pfade

PfadeJSON, YAML

Beide beschreiben den Weg zu einem Wert. Ein JSON Pointer zeigt immer auf genau eine Stelle. Ein jq-Pfad kann auch viele Stellen auf einmal treffen und gleich weiterrechnen.

Dein gewählter Wert: 2.59
Zeiger
/bestellungen/1/positionen/0/preis
jq
.bestellungen[1].positionen[0].preis

So sind sie gebaut

TeilJSON Pointerjq-Pfad
Ganzes Dokument"".
Schlüssel/kunde.kunde

Schlüssel "a/b"/a~1b.["a/b"]
Schlüssel "a~b"/a~0b.["a~b"]

Beide zählen Listen ab 0. Im Zeiger stehen ~1 für einen Schrägstrich und ~0 für eine Tilde im Schlüssel.

Wann welcher?

  • Zeiger, wenn genau eine Stelle gemeint ist: in JSON Schema bei $ref, in Fehlermeldungen beim Validieren, für Änderungen an einer Stelle.
  • jq, wenn du suchst, filterst oder umbaust. Die Abfrage unten im Arbeitsplatz versteht jq direkt.
